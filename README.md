# AeroShield

AeroShield is a simulation-first R&D software prototype for sensor monitoring, diagnostics, simulated telemetry, digital-twin visualization, geospatial simulation, and validation.

## Scope

- Simulated multi-sensor data streams
- Data acquisition and validation
- Sensor-health and data-quality monitoring
- Fault injection and diagnostic events
- Simulated telemetry and event logging
- 3D digital-twin visualization
- Geospatial simulation and track visualization
- Scenario-based verification and validation

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Leaflet
- Three.js
- Motion

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

The development server starts on port 3000.

## Production build

```bash
npm run build
npm run preview
```

## Prototype boundary

This repository contains an academic software simulation / R&D prototype. Sensor values, telemetry, tracks, and test results shown by the application are simulated data and are intended for software demonstration and validation workflows.
